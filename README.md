# TUR11 — Matchday Journal

Самостоятельная браузерная версия TUR11. В ней можно создать клуб, управлять составом 1–3–4–3, назначать капитана, менять игроков на той же позиции в пределах бюджета и играть одну дуэль с ИИ в день.

Прогресс хранится только в `localStorage` текущего браузера. У сайта и Android-приложения нет аккаунтов, сервера или синхронизации: в каждой версии — отдельный локальный прогресс.

## Партнёрские ссылки

Внешние HTTPS-ссылки Winline, BetBoom, PARI и Fonbet заданы прямо в `index.html`. Меняйте их только на выданные и разрешённые партнёрские ссылки.

Каждая рабочая ссылка открывается в новой вкладке только после подтверждения 18+. Не удаляйте предупреждения, маркировку рекламного раздела и информацию о рисках.

## Политика конфиденциальности

Страница `privacy.html` опубликована через GitHub Pages: `https://whylegend.github.io/tur11-landing/privacy.html`. Этот постоянный адрес используйте в карточке TUR11 в RuStore. Подробные шаги — в `GITHUB_PAGES.md`.

## Временный предпросмотр

Для локального запуска: `python -m http.server 8080` из этой папки. Временный публичный URL создаётся отдельно через туннель и действует, пока работает локальный процесс.
